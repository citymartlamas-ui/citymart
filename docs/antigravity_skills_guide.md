# 🚀 Guía de Uso: Antigravity Awesome Skills

¡Felicidades! Tu entorno de desarrollo ahora cuenta con más de **1,400 skills (habilidades agenticas)** diseñadas para potenciar cada etapa de la construcción de **CityMart**. Estas habilidades actúan como "playbooks" o manuales expertos que yo, como tu asistente, puedo seguir para garantizar resultados de nivel profesional.

## 🛠️ Cómo invocar una Skill
Para usar una habilidad, simplemente menciónala en tu solicitud usando el prefijo `@`. Por ejemplo:
> *"@ui-ux-pro-max revisa la página de inicio y sugiera mejoras para que se vea más premium."*
> *"@firebase optimiza las reglas de seguridad de mi base de datos."*

## 🌟 Skills recomendadas para CityMart

He seleccionado las mejores habilidades que se alinean perfectamente con tu proyecto actual:

### 1. Backend y Base de Datos
*   **`@firebase`**: Optimización de Firestore, funciones en la nube y configuración de hosting.
*   **`@postgresql`**: Por si decides escalar a bases de datos relacionales más complejas.
*   **`@nosql-expert`**: Diseño de esquemas eficientes para datos en tiempo real.

### 2. Diseño y Experiencia de Usuario (UI/UX)
*   **`@ui-ux-pro-max`**: Aplicación de principios de diseño moderno, jerarquía visual y accesibilidad.
*   **`@high-end-visual-design`**: Enfoque en estéticas de lujo, gradientes suaves y micro-animaciones.
*   **`@minimalist-ui`**: Limpieza visual para que la información de la ciudad sea fácil de leer.

### 3. Crecimiento y SEO
*   **`@seo-audit`**: Análisis completo de metadatos, estructura de encabezados y rendimiento para buscadores.
*   **`@marketing-psychology`**: Estrategias para hacer que las promociones y noticias sean más atractivas para los usuarios.
*   **`@programmatic-seo`**: Creación de miles de páginas optimizadas para diferentes categorías de negocios.

### 4. Calidad y Rendimiento
*   **`@progressive-web-app`**: Mejora de la experiencia offline y notificaciones push (ya que CityMart tiene un `sw.js`).
*   **`@clean-code`**: Refactorización de `scripts.js` y otros archivos para mantener el código mantenible.
*   **`@performance-optimizer`**: Reducción de tiempos de carga en imágenes y scripts pesados.
